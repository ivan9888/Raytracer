# Raytracer in Java

A ray tracing engine developed in Java using Object-Oriented Programming principles to render realistic 3D scenes with lighting, shadows, and reflections.

## Overview

This project implements a custom ray tracing renderer from scratch in Java. The engine simulates how light rays interact with objects in a 3D environment to generate realistic rendered images.

The project focuses on:

- Computer Graphics fundamentals
- Ray tracing algorithms
- Object-Oriented Design
- Mathematical rendering techniques
- 3D scene simulation

## Features

- Ray-object intersection detection
- Diffuse and specular lighting
- Shadows
- Reflections
- Refraction
- Camera and viewport system
- Recursive ray tracing
- Scene rendering pipeline
- OOP-based architecture
